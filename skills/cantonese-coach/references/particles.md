# 语气词手册（14 个高频）

粤语的语气词承载"态度"，不是可有可无的装饰。少一个语气词，句子就变成书面语。

| 词 | 粤拼 | 作用 | 例句 | 普通话 |
|---|---|---|---|---|
| 啦 | laa1 | 请求、建议，软一点 | 一齊去啦。 | 一起去嘛。 |
| 喇 | laa3 | 强调"已经这样了 / 就这样定了" | 我做晒喇。 | 我全做完了。 |
| 囉 | lo1 | "不就这样吗"，理所当然 | 你話唔去囉。 | 那你说不去就不去咯。 |
| 喎 | wo3 | 转述别人、表示意外 | 佢話唔得閒喎。 | 他说没空呢。 |
| 咩 | me1 | 反问"难道……吗" | 你唔知咩？ | 你不知道吗？ |
| 啩 | gwaa3 | 推测，"大概吧" | 佢應該嚟啩。 | 他应该会来吧。 |
| 嘅 | ge3 | 所属 / 肯定语气 | 我嘅書。 | 我的书。 |
| 呀 | aa3 | 缓和、追问 | 你去邊呀？ | 你去哪儿呀？ |
| 嘛 | maa3 | 举例强调 | 食飯嘛，好簡單。 | 吃饭嘛，很简单。 |
| 添 | tim1 | 追加，"还……呢" | 仲要加錢添。 | 还要加钱呢。 |
| 先 | sin1 | 粤语特有序法：先做某事 | 你行先。 | 你先走。 |
| 吓 | haa5 | 稍微、短暂 | 等吓先。 | 先等一会儿。 |
| 㗎 | gaa3 | 肯定 + 强调 | 係咁㗎。 | 就是这样子的。 |
| 咋 | zaa3 | "只是……而已" | 得兩蚊咋。 | 只有两块钱而已。 |

## 容易混的三组

**啦 / 喇 / 囉** —— 都是句尾软化，但方向不同：
- `啦 laa1`：我在**请你**做某事（一齊去啦）。
- `喇 laa3`：事情**已经/只能**这样了（做晒喇）。
- `囉 lo1`：这**不是明摆着**吗（你話唔去囉），带一点无奈或顶嘴。

**咩 / 呀** —— 都是问句结尾：
- `咩 me1`：我**不信/有意见**（你唔知咩？＝你怎么会不知道）。
- `呀 aa3`：中性提问，只把语气放软（你去邊呀？）。

**嘅 / 㗎** —— 都是"是……的"：
- `嘅 ge3`：所属（我嘅書）。
- `㗎 gaa3`：断言（係咁㗎＝就是这样子的）。

## 两个非语气词的"语序标记"

- `先 sin1`：放句尾表示"先做"——`你行先`（你先走）、`食飯先`（先吃饭）。
- `添 tim1`：放句尾表示追加——`仲要加錢添`（还要加钱呢）。

普通话里这些意思靠副词位置，粤语靠句尾。这是最容易露馅的地方，也是最快速"像本地人"的地方。

## 练习法

1. 挑一句你已经会说的粤语，去掉语气词，再补回去，对比差别。
2. 用 `mcp__hkchat__yue_quiz(mode="particle", count=10)` 做填空。
3. 每周只主攻 2 个语气词，写进语块本，在真人对话里故意用 3 次。
