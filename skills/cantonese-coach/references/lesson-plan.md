# 四週計畫與里程碑

目標（課程要求）：掌握粤拼六调 · 200-300 高频词 · 每天 5-15 分钟听说 · 每周 2 次 × 15 分钟真人对话 · 每周自测 ≥80%。

## 每週固定动作

| 时间 | 动作 | 工具 / 产出 |
|---|---|---|
| 週一 | 定场景：本週主攻 2 个场景 + 2 个语气词 | `yue_roleplay` 出稿 |
| 每天 5-15 分钟 | si1-si6 六连读 2 分钟 + 场景跟读 5-10 分钟 | `yue_log(action="add")` |
| 週三 / 週六 | 真人对话 15 分钟（课前预演 10 分钟、课后复盘 10 分钟） | `yue_rewrite` 改写 5 句 |
| 週日 | 自测 4 类各 5 题，取总分 | `yue_quiz` + `yue_log(score=…)` |
| 週日 | `yue_log(action="summary")` 出周报，补语块本 | 语块本 CSV |

## 四週安排

### 第 1 週：先摸到调
- 主攻：六调 + 20 个最高频词（係/唔/冇/佢/呢個/嗰個/食/飲/去/嚟…）。
- 每天：si1-si6 六连读；`yue_explain(item="声调")` 读一遍。
- 自测：`yue_quiz(mode="tone", count=10)`，目标 ≥80%。
- 里程碑：能听出"平 / 升 / 降"三组的差别；不必六调全对，能分辨即可。

### 第 2 週：高频词 + 否定
- 主攻：动词 30 个 + 否定系统（唔 / 冇 / 唔使 / 唔好 / 未）。
- 每天：`yue_rewrite` 把当天想到的 3 句普通话改写成粤语。
- 自测：`yue_quiz(mode="vocab", count=10, seed="W2")`。
- 里程碑：能不看粤拼说出「我唔食」「佢冇嚟」「你唔使等」。

### 第 3 週：语气词 + 场景
- 主攻：啦 / 喇 / 咩 / 喎 四个语气词；茶餐厅 + 街市两个场景。
- 每天：`yue_roleplay(scene="茶餐廳", turns=4)` 跟读 + 遮台词接话。
- 自测：`yue_quiz(mode="particle", count=10)`。
- 里程碑：能独立点完一餐（饮品 + 主食 + 少甜 + 埋单）。

### 第 4 週：真人对话冲刺
- 主攻：问路 + 约朋友；把前 3 週语块本里"会忘"的句子筛出来重练。
- 每天：`yue_roleplay(scene="問路")` + 拿真人对话的录音/笔记复盘。
- 自测：四类各 5 题，总分 ≥80%。
- 里程碑：能用粤语完成一次 3 分钟以上、含问句与语气词的日常对话。

## 语块本目标

- 每週新增 10-15 条，四周合计 40-60 条 → 覆盖 200-300 词。
- CSV 列：`日期,粤语,粤拼,普通话,场景,语气词,我的错点`
- 复习规则：能脱稿说出的划掉；连续两次说错的标红，下周优先。

## 自测评分口径

- 总分 = 四类题型正确率的平均，**≥80% 达标**。
- 未达标不刷题：只把错题分类（词汇记错 / 声调听错 / 语气词选错），隔天换种子重测同一类。
- 记录进 `yue_log`，週报看趋势而不是看单次分数。
